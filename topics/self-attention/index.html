The Big Picture & Intuition

"Why do words need to look at each other?"

In human language, a single pronoun like "it" completely changes meaning depending on a single adjective at the end of the sentence. Before Self-Attention, static word embeddings gave "it" the exact same vector every time.

📚 The Search Engine / Library Analogy ($Q$, $K$, $V$)

How does a word mathematically "look for" relevant words? Every input word vector $x_i$ is multiplied by three learned weight matrices ($W_Q, W_K, W_V$) to create three distinct vectors:

QUERY (Q) · Cyan

"What am I looking for?"

Like typing a search query into Google. When the word "it" is the active token, its Query $q_{\text{it}}$ searches the sentence for a singular noun that matches the predicate ("tired" vs "wide").

Formula: $Q = X W_Q$
KEY (K) · Amber

"What do I contain / advertise?"

Like the title and tags on the spine of a library book. Every word broadcasts a Key $k_j$ advertising its grammatical and semantic features (e.g., "animate noun" or "physical object").

Formula: $K = X W_K$
VALUE (V) · Emerald

"What information do I pass along?"

Like the actual pages inside the book once opened. Once Query $q_i$ and Key $k_j$ match with a high attention weight $\alpha_{ij}$, the word absorbs $\alpha_{ij} \cdot v_j$!

Formula: $V = X W_V$

🔀 Why Multi-Head Attention? (Running Multiple $Q, K, V$ Heads in Parallel)

A single attention head can only focus on one dominant relationship per token. Multi-Head Attention splits $d_{\text{model}}$ into $h$ smaller subspaces (e.g., $h=8$ heads of $d_k = 64$ each) and runs Scaled Dot-Product Attention in parallel: Head 1 can track pronoun coreference ("it" → "animal"), Head 2 can track verb-object grammar ("cross" → "street"), and Head 3 can track adjective intensity ("too" → "tired"). Their outputs are concatenated and projected via $W_O$.

Minimal PyTorch Implementation & Self-Check Flashcards

Code + Active Recall

Every line of the PyTorch implementation below maps 1-to-1 to Stages 3, 4, and 5 of our visual pipeline: 

import math
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    # Q, K, V shapes: (batch_size, num_heads, seq_len, d_k)
    d_k = Q.size(-1)

    # Stage 3: Similarity Scores (Q · K^T) -> shape: (..., seq_len, seq_len)
    scores = torch.matmul(Q, K.transpose(-2, -1))

    # Stage 4a: Scale by sqrt(d_k) to prevent Softmax saturation
    scaled_scores = scores / math.sqrt(d_k)

    # Optional Causal Mask (for GPT decoders): set future tokens to -inf
    if mask is not None:
        scaled_scores = scaled_scores.masked_fill(mask == 0, float("-inf"))

    # Stage 4b: Row-wise Softmax -> probabilities summing to 1.0 (100%)
    attn_weights = F.softmax(scaled_scores, dim=-1)

    # Stage 5: Weighted Sum of Values (Weights · V) -> shape: (..., seq_len, d_v)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

🃏 Self-Check Flip Flashcards (Click any card to flip)

Test your intuition on the 4 classic interview & research questions about Self-Attention:

Question 1 of 4 · Click to Flip

Why do we need separate $Q$, $K$, and $V$ instead of just multiplying $X \cdot X^T$?

Hint: Think symmetry & roles
Answer 1

$X \cdot X^T$ is forced to be symmetric (A attends to B equally as B attends to A) and makes every word attend maximally to itself. Separate $Q, K, V$ projections enable asymmetric routing (e.g., pronoun "it" querying noun "animal") and decouple matching ($Q, K$) from content ($V$).

Question 2 of 4 · Click to Flip

Why divide by $\sqrt{d_k}$ before applying Softmax?

Hint: What happens when $d_k$ is large?
Answer 2

If $q$ and $k$ have unit variance, their dot product $q \cdot k$ has variance $d_k$ (std $\sqrt{d_k}$). For large $d_k$, dot products grow huge, pushing Softmax into flat regions where gradients vanish ($\approx 0$). Dividing by $\sqrt{d_k}$ restores unit variance!

Question 3 of 4 · Click to Flip

What is the shape of the Attention Matrix for a sequence of $N$ tokens?

Hint: Why are long contexts expensive?
Answer 3

Since every token's Query ($N \times d_k$) dot-products with every token's Key ($d_k \times N$), the attention matrix per head has shape $N \times N$. This gives Self-Attention $O(N^2)$ time and memory complexity.

Question 4 of 4 · Click to Flip

How does Causal Masking (in GPT decoders) change Stage 3/4?

Hint: How do we block future tokens?
Answer 4

Right before Softmax, all upper-triangular entries $(j > i)$ in the $N \times N$ score matrix are set to $-\infty$. Because $e^{-\infty} = 0$, Softmax assigns exact $0\%$ weight to all future tokens!
